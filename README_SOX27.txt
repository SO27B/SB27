# SO X27 Portfolio — Version finale polie

## Fichiers inclus
- `index.html`
- `generic.html`
- `elements.html`
- `assets/css/sox27-platform.css`
- `assets/js/sox27-platform.js`

## Installation
Copie tout le contenu du zip dans ton dossier portfolio en remplaçant les anciens fichiers.

## Test
Si ton portfolio est en HTML simple :
- clic droit sur `index.html`
- Open with Live Server

Si ton portfolio est Vite/React :
```powershell
npm.cmd install
npm.cmd run dev
```

## Vérifications
1. Le fond neuronal 3D doit bouger doucement.
2. Le terminal SO X27 doit répondre à : `status`, `projects`, `vision`, `about`.
3. Le bouton micro doit demander l'autorisation du navigateur.
4. La section Industrial Vision AI doit apparaître.
5. La section Engineering Projects doit apparaître.
6. Sur téléphone, les cartes doivent passer en colonne.

## À personnaliser ensuite
